# Day 06 - Pattern Programs

## 📌 Introduction

Day 06 focuses on Java pattern programs using loops and nested loops.

Pattern programs help to improve logical thinking and understand how rows,
columns, spaces, stars, and numbers work together.

## 🎯 Topics Covered

- Nested for loop
- Rows and columns
- Star patterns
- Number patterns
- Spaces
- Triangle patterns
- Square patterns
- Pyramid patterns
- Floyd's Triangle
