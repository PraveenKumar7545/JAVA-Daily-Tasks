# ☕ JAVA-Daily-Tasks

A structured **15-Day Java Practice Repository** created to build strong Java programming fundamentals through daily coding practice.

This repository contains **Java programs, problem-solving exercises, screenshots of program outputs, and practice questions** completed during my Java learning journey.

The main goal is to improve **Java programming, logical thinking, problem-solving, and coding consistency** through hands-on practice.

---

## 📌 About This Repository
 
This repository documents my Java learning progress from **basic Java concepts to Object-Oriented Programming, Collections, Exception Handling, File Handling, and Mini Projects**.

Each day contains:

* 📝 Practice Questions
* 💻 Java Solutions
* 🖥️ Output Screenshots
* 📖 Day-wise README

The screenshots provide **visual proof of the program outputs** for the completed practice tasks.

## ▶️ How to Compile and Run

Navigate to the required `Solutions` folder.

### Compile

```bash
javac Q01_Student_Class.java
```

### Run

```bash
java Q01_Student_Class
```

The same method can be used for the other Java programs.

### Example

```bash
javac Q10_Array_of_Objects.java
java Q10_Array_of_Objects
```
