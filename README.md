## ▶️ How to Compile and Run

Java programs can be compiled and executed using the terminal in VS Code, Command Prompt, or PowerShell.

### Prerequisites

- Java Development Kit (JDK) installed
- Java compiler (`javac`) available in the system PATH
- VS Code or another Java-compatible editor

Verify your Java installation:

```powershell
java -version
javac -version
```

### Step 1 — Navigate to a Solutions folder

Example for Day 11:

```powershell
cd "C:\Disk D\Full Stack fol\JAVA-Daily-Tasks\Day-11-OOP-Basics\Solutions"
```

### Step 2 — Compile a Java program

```powershell
javac Q01_Student_Class.java
```

### Step 3 — Run the program

```powershell
java Q01_Student_Class
```

### Compile all Java programs in a day's Solutions folder

```powershell
javac *.java
```

After compilation, run each program individually using its class name, without the `.java` extension.

**Note:** Some programs require user input. Enter the requested values in the terminal. File-handling programs may also create text files when executed.
