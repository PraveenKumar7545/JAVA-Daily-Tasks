# Day 07 - Arrays Basics

## 📌 Introduction

Day 07 of my Java Daily Tasks focuses on **Arrays Basics**.

An array is used to store multiple values of the same data type in a
single variable.

In this day, I practiced creating arrays, storing elements, accessing
elements, performing calculations, searching elements, reversing arrays,
and copying arrays.

---

## 🎯 Objectives

The main objectives of Day 07 are:

- Understand the basics of arrays
- Learn array declaration and initialization
- Store multiple values in an array
- Access array elements using indexes
- Use loops with arrays
- Calculate the sum and average of array elements
- Find the largest and smallest elements
- Count even and odd numbers
- Reverse an array
- Search for an element
- Copy elements from one array to another

---

## 📚 Topics Covered

- Array declaration
- Array initialization
- Array indexing
- Array length
- `for` loop with arrays
- User input with arrays
- Sum of array elements
- Average of array elements
- Largest element
- Smallest element
- Even and odd count
- Reverse array
- Linear search
- Copying arrays
